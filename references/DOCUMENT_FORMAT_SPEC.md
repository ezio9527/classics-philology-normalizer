## 1. 格式制定宗旨与核心原则

古籍文献历经数百年传抄、木刻雕版、铅印及现代 OCR/网络爬虫采集，普遍存在版面腐化与体例失序。本规范旨在建立一套**对机器解析高度确定（Machine-Deterministic）**且**对人类阅读清爽典雅（Human-Centric）**的古籍 Markdown 黄金标准。

### 两大核心铁律
1. **正文绝对保真原则 (Zero Semantic Mutation)**：
   严禁以现代白话文改写古汉语；严禁主观“纠错字”（异体字、古通假字、断句及作者原笔误必须 100% 保留）。
2. **纯文本相似度门禁 (Text Diff Invariance $\ge 99.8\%$)**：
   剥离 Markdown 语法标记后的汉字与标点字符流，与古籍底本的相似度必须达到 99.8% 以上。

## 2. 宏观文档组织与 AST 拓扑规范

### 2.1 全局根节点 (H1)
* **唯一性**：全篇文档**有且仅允许出现 1 个一级标题**，位于文档第 1 行。
* **命名格式**：`# 《书名》`（可附带版本考据括号，如 `# 《滴天髓阐微》（清·任铁樵注本）`）。
* **禁止事项**：正文中间任何卷、篇、章严禁再次出现 `#` 标题。

### 2.2 序言、凡例与总目录 (TOC) 多级扩展准则

#### 2.2.1 目录多级扩展的文献学与工程必要性
传统古籍版本常区分**“总目”**（仅录卷名，如卷一、卷二）与**“细目/子目”**（详列卷下诸篇、论题）。
在数字化 Markdown 文档中，**若目录仅收录二级标题（如仅列 `## 卷一`），读者和自动化系统将完全丧失对卷下数十个核心论题的检索导航能力**。因此，**必须对目录进行规范化多级扩展**。

#### 2.2.2 目录展开黄金深度准则 (TOC Depth Standard)
目录并非越深越好，必须遵循“最佳导航信息熵”原则，依三大编纂范式精确约束展开深度：
* **范式 A【汇编全书型】（展开至 H3）**：
  - 必须展开至 **H2 卷 $\to$ H3 篇/章**（如 `[卷一]` $\to$ `[论五行生成]`）；
  - **严禁展开 H4 细碎歌赋/小节**，保持总目录提纲挈领。
* **范式 B【主干经注型】（展开至 H3）**：
  - 必须展开至 **H2 篇 $\to$ H3 核心论章**（如 `[通天论]` $\to$ `[论天道]`）；
  - **严禁将 H4 名家评注（如 `【任氏曰】`）与 H5 命造实证列入总目录**，避免一部典籍数百例命盘将目录冲垮为上千行流水账。
* **范式 C【纲目矩阵型】（严格截止至 H3，绝不下潜 H4）**：
  - 必须展开至 **H2 月令(纲) $\to$ H3 日主(目)**；
  - **绝对禁止将 H4 时辰条目展开至总目录**（否则 $12 \times 10 \times 12 = 1440$ 个时辰会导致目录瞬间膨胀至 1500 行产生灾难性冗余！各时辰检索直接在日主章内定位即可）。

#### 2.2.3 目录多级展开标准范例
```markdown
# 《三命通会》

> **版本考据**：明·万历戊寅年（1578年）进士育吾山人万民英纂辑。钦定四库全书子部术数类存目。

## 序

夫三命之作，肇端于上古……

## 凡例

一、是书采摭诸家之善……

## 目录

- [卷一](#卷一)
  - [论五行生成](#论五行生成)
  - [论干支源流](#论干支源流)
- [卷二](#卷二)
  - [论十干分配天文](#论十干分配天文)
  - [论十二支分配地理](#论十二支分配地理)
```

#### 2.2.4 自动化生成与文字保真门禁解耦
* **自动化生成**：可直接调用 `python3 resources/scripts/normalizer_tools.py expand-toc -i book.md -o book.md -d 3` 依据正文 AST 树一键重构并更新多级目录；
* **门禁解耦**：`diff_verifier.py` 在计算文字保真度时，会自动识别并剥离 `## 目录` 导航元数据块，因此**目录多级扩展不会误触发古籍正文字数漂移警报**。

## 3. 三大古典文献范式结构标准

不同流派与编纂体裁的古籍，必须对应适配其专属的 Markdown AST 拓扑：

### 3.1 范式 A【汇编全书型】
* **典型书目**：《三命通会》《渊海子平》《神峰通考》《星平会海》
* **层级拓扑**：
  $$\text{H1: 书名} \longrightarrow \text{H2: 卷 N (宏观容器)} \longrightarrow \text{H3: 篇/章 (论题)} \longrightarrow \text{H4: 小节/歌赋}$$
* **结构约束**：
  - `## 卷一` 为最高宏观分界容器；
  - 卷下诸论题统一使用 `###`；
  - 若篇章下有附歌、附赋或细分推导，使用 `####`。

### 3.2 范式 B【主干经注型】
* **典型书目**：《滴天髓阐微》《子平真诠》《穷通宝鉴》（徐注本）
* **层级拓扑**：
  $$\text{H1: 书名} \longrightarrow \text{H2: 宏观篇/卷} \longrightarrow \text{H3: 核心论章} \longrightarrow \text{经文/原注/名家评注/命例}$$
* **结构约束**：
  - H2 为分篇（如 `## 通天论`、`## 理气论`）；
  - H3 为论题核心（如 `### 论天道`）；
  - 经文成段，原注进引用块，名家评注采用 `####` 四级标题，命例采用 `#####` 五级标题。

### 3.3 范式 C【纲目矩阵型】
* **典型书目**：《八字提要》《穷通宝鉴》（原文条目）
* **层级拓扑**：
  $$\text{H1: 书名} \longrightarrow \text{H2: 月令 (纲容器)} \longrightarrow \text{H3: 日主 (目章节)} \longrightarrow \text{H4: 时辰条目 (条)}$$
* **致命反模式与绝对禁令**：
  - ❌ **严禁写为**：`### 寅月甲日甲子时` 或 `### 寅月甲日` 混合。
  - ✅ **必须严格拆解**：
    ```markdown
    ## 寅月

    ### 甲日

    #### 甲子时
    甲木得禄于寅，又见子水相生……

    #### 乙丑时
    甲生寅月，时临乙丑……
    ```

## 4. 微观文献元素详细排版规范

### 4.1 经文原著正文
* **表现形态**：Markdown 普通自然段落。
* **规范要求**：
  - 顶格书写，段首不使用全角或半角空格缩进（遵循现代 Markdown 原则）；
  - 保持原著文言语句古意，严禁私自加粗或斜体（加粗仅用于元标签）。

### 4.2 双行小字夹注（原注）
* **古典渊源**：传统雕版古籍中紧随正文下方的“双行小字注”。
* **表现形态**：Markdown 引用块（`> `）。
* **标准语法**：
  ```markdown
  欲识三元万法宗，先观帝载与神功。

  > **【原注】**：天有阴阳，地有刚柔，人道得之，以理气相顺而成天地之造化也。
  ```

### 4.3 后世名家评注疏解
* **典型作者**：任铁樵、徐乐吾、沈孝瞻、万民英等。
* **表现形态**：四级标题（`####`）标识评注者称谓，评述正文另起独立自然段。
* **标准语法**：
  ```markdown
  #### 【任氏曰】

  帝载神功，即阴阳造化之妙也。生生不息，变化无穷，其理微矣。学者若不知阴阳神功之大化，徒泥于星宿神煞之末节，乌足语三元之奥哉！
  ```
* **禁止事项**：严禁在 `#### 【任氏曰】` 标题行内直接追加评注正文！

### 4.4 八字命造实证排盘表格
命理典籍的核心论证工具为干支八字实测命例。必须标准化为**结构化四柱排盘表格**。

* **标准语法结构**：
  ```markdown
  ##### 命例：某提督造

  | 年柱 | 月柱 | 日柱 | 时柱 |
  | :---: | :---: | :---: | :---: |
  | 戊辰 | 癸亥 | 甲子 | 丁卯 |

  **评析**：甲木生于亥月，天干透癸，水势旺极。妙在年透戊土，砥柱中流，时见丁火卯木，泄秀生财。位至提督，声震边陲。
  ```
* **技术规约**：
  1. 标题必须为五级标题：`##### 命例：[命主身份/造化称谓]`；
  2. 表头必须且只能包含 4 列：`| 年柱 | 月柱 | 日柱 | 时柱 |`；
  3. 对齐方式固定为居中：`| :---: | :---: | :---: | :---: |`；
  4. 第二行为 4 组干支（每个单元格严格为 2 个汉字，如 `戊辰`）；
  5. 表格下方空一行，以 `**评析**：` 引出古籍原文对其命理吉凶的分析断语，**原文一字不漏**。

### 4.5 韵文、歌赋与口诀
* **包含品类**：总赋、万金赋、口诀、赞颂、五行歌诀等。
* **表现形态**：Markdown 引用块（`> `），各句单独成行。
* **标准语法**：
  ```markdown
  #### 原起总赋

  > 混沌初分，洪濛始判。
  > 气之清轻上浮者为天，气之重浊下凝者为地。
  > 阴阳播五行之气，相生相克，万物资始。
  ```

### 4.6 校勘记与编者按语
若整理者在对勘不同版本（如四库本 vs 宝颜堂秘笈本）时发现版本异文，统一使用引用块并以加粗标签标注：
```markdown
> **【校勘记】**：元刊本作“大挠作甲子”，明万历本讹作“大挠造甲子”，今据元刊本及《史记·历书》从“作”。
```

## 5. 空格、换行与标点符号规范

1. **段落间距**：不同标题、段落、引用块、表格之间，必须且仅保留 **1 个空行**（即 2 个换行符 `\n\n`）。禁止出现连续 3 个及以上的空白行。
2. **段首缩进**：行首严禁使用全角空格 `\u3000\u3000` 或 HTML `&emsp;`。Markdown 由渲染器控制段落间距，文档源码一律左侧顶格。
3. **标点统一**：古籍标点全部使用全角中文标点（`，`、`。`、`、`、`；`、`！`、`？`、`：`、`《`、`》`、`“`、`”`）。表格与语法标签中的冒号与竖线除外。

## 6. 排版负面清单与杂音清洗白名单

### 6.1 绝对禁止的八大反模式 (Negative Patterns)
| 违规项 | 错误代码示范 | 正确标准示范 |
| :--- | :--- | :--- |
| **白话篡改** | 将“甲木参天”写为“甲木是一种参天大树” | 必须原样保留“甲木参天” |
| **标题回声** | `## 论五行\n### 论五行` | 删除重复的 `### 论五行` |
| **标题越位** | `### 【徐注】阴阳之说，最为...` | `#### 【徐注】\n\n阴阳之说...` |
| **多重根标题**| 文中多次出现 `# 卷二` | 仅首行书名使用 `#`，卷使用 `##` |
| **时辰合并** | `### 寅月甲日甲子时` | `## 寅月` $\to$ `### 甲日` $\to$ `#### 甲子时` |
| **八字成文** | 散文中直接写“如某提督戊辰癸亥甲子丁卯亥月透癸” | 拆解为五级标题 + 四柱表格 + 评析 |
| **口诀散文** | 赋文连写在一行不分断句 | 引用块 `> ` 逐句对仗排版 |
| **私改异体** | 将“旡”擅改“无”，将“炁”擅改“气” | 100% 尊重底本原字保留 |

### 6.2 允许清除的非正文杂音白名单 (Allowed Noise Cleaned)
* 爬虫分页符：`第 1 页`、`第 1/12 页`、`[上一页]`、`下一页`、`首页`、`尾页`、`返回目录`
* 来源链接与水印：`源站地址：...`、`http://...`、`https://...`、`www...`、`关注公众号...`
* OCR 系统免责残余：`OCR识别结果仅供参考`、`作者整理发布`

## 7. 端到端黄金示范文档 (Golden Sample)

```markdown
# 《滴天髓阐微》

> **版本考据**：京图撰，宋·刘基（伯温）原注，清·任铁樵增辑阐微，民国·徐乐吾校订。

## 目录

- [通天论](#通天论)
  - [论天道](#论天道)
  - [论地道](#论地道)

---

## 通天论

### 论天道

欲识三元万法宗，先观帝载与神功。

> **【原注】**：天有阴阳，地有刚柔，人道得之，以理气相顺而成天地之造化也。

#### 【任氏曰】

帝载神功，即阴阳造化之妙也。生生不息，变化无穷，其理微矣。命理之学，法宗乎此。学者若不知阴阳神功之大化，徒泥于星宿神煞之末节，乌足语三元之奥哉！

##### 命例：某提督造

| 年柱 | 月柱 | 日柱 | 时柱 |
| :---: | :---: | :---: | :---: |
| 戊辰 | 癸亥 | 甲子 | 丁卯 |

**评析**：甲木生于亥月，天干透癸，水势旺极。妙在年透戊土，砥柱中流，时见丁火卯木，泄秀生财。位至提督，声震边陲。

---

### 论地道

坤元合德机缄通，五气偏全定吉凶。

> **【原注】**：地道主静，以承天之施。方圆动静，各具性情，五气顺遂则吉，乖戾则凶。

#### 【任氏曰】

地道虽静，其机常动。五行之气，在天为风热湿燥寒，在地为木火土金水。顺天地之流行，方明休咎之精微。
```

## 8. 面向 SEO 静态站的原子化章节拆分与 Frontmatter 规约

### 8.1 为什么必须对单体古籍进行 SEO 原子化切分？
单体古籍文档（动辄 3~30 万字）直接发布于现代静态站点（Astro, Hugo, Next.js, VitePress）存在以下致命缺陷：
1. **搜索关键词稀释（Thin Keyword Match）**：读者检索“论五行生成”时，整书单页标题只能匹配书名，难以在 SERP（搜索引擎结果页）取得高排名；
2. **首屏性能劣化（LCP 恶化）**：超长页面产生上万 DOM 节点，大幅降低页面加载速度；
3. **缺乏深层内链拓扑**：单页无法形成“上一篇/下一篇/分卷聚合/面包屑”的紧密内链网，爬虫抓取深度严重受限。

因此，**将规范化单体古籍按“黄金原子单元”拆解为静态站独立文章页，是实现古籍互联网高权重传播的必由之路**。

### 8.2 三大编纂范式的切分粒度标准
* **范式 A【汇编全书型】（切至 H3 篇章）**：
  每个篇章（如《论五行生成》）独立为一页（800~3000 字），H2 卷为分卷聚合页。
* **范式 B【主干经注型】（切至 H3 核心论章）**：
  每个论章（如《天道》）独立为一页（1000~4000 字），包含经文、双行原注、任氏阐微与数例命造，内容丰满。
* **范式 C【纲目矩阵型】（切至 H3 日主目，包裹 12 时辰）**：
  **核心 SEO 门禁**：每个日主（如《寅月·甲日》）独立为一页（约 1500 字），内含该日主的 12 个时辰断语。**严禁拆分为 1440 个时辰微页面**，避免因页面字数过少被判定为“薄内容（Thin Content）”遭到降权。

### 8.3 目标静态站目录组织拓扑
```text
dist_seo/
└── {book_slug}/
    ├── index.md                      # 全书总览页 (Book Hub): 版本考据 + 全书总目
    ├── site_manifest.json            # 站点全量元数据清单
    ├── {volume_slug}/
    │   ├── index.md                  # 分卷聚合页 (Volume Hub): 卷导读 + 篇目链接
    │   ├── 01_{chapter_slug}.md      # 原子文章内容页: 带 Frontmatter + 纯正文
    │   ├── 02_{chapter_slug}.md
    │   └── ...
    └── ...
```

### 8.4 原子章节标准 YAML Frontmatter 规约
